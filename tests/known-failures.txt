# The tests the suite expects to fail, by decision 30 of "Decisions of
# 2026-10-11" in docs/decisions.md. Each shows a defect of antic or anti
# and is written as the rule says the program must behave.
#
# One line per test: the name of the test, the id of its finding in
# docs/audit/tests-findings.md and one sentence, separated by one space
# each.
#
#   matrix_case_copy_dev T001 A field of a case reads 0 after a copy.
#
# A defect that shows on some hosts alone ends its line with `host=` and
# their systems, `macos`, `linux` or `windows`, with a `,` between two.
# The suite of such a host expects the test to fail, and that of every
# other host expects it to pass.
#
#
# tests/CMakeLists.txt sets WILL_FAIL on every listed test, so a listed
# test that passes fails the suite. The fix of a finding removes its lines.
# The test known_failures checks the list against the table of the findings.

anti_build_lock_path_moved T298 The lock file keeps the old path of a dependency whose new path holds the same library.
anti_build_lock_package_without_a_version T299 A package of the lock file without its version ends the list, and the build keeps the lock file without the packages after it.
anti_build_lock_module_without_a_digest T299 A module of the lock file without its digest ends the list of the package, and the build does not find the module.
anti_build_message_index_dependency_without_a_name T300 A dependency of the index without its name ends the list, and the walk drops it without a word.
anti_build_message_index_module_without_a_digest T300 A module of the index without its digest ends the list, and the version names no module.
anti_build_message_index_version_without_a_version T300 A version of the index without its version ends the list, and the versions after it leave the index.
