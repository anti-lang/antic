# The messages of antic and of anti that no test expects yet. The test
# diagnostics_covered reads this list beside the sources and the expected
# outputs under tests/. tests/run_diagnostics_covered.cmake states how it
# reads each.
#
# One line per message: its format as the C source writes it, with the
# pieces of the literal joined. A line that starts with `#` names the file
# that gives the messages after it, for the reader alone.
#
# A message that stays for good has the lines `# Stays: ...` before it,
# which give the reason. Either no program and no input a test can write
# reaches it, or antic gives it as the second message of one mistake alone,
# and a finding of docs/audit/tests-findings.md holds that. The test reads
# a line as one message, so the reason stands in lines of its own.
#
# A message leaves the list in the commit that adds its test. The test
# fails for a line whose message a test expects, and for a message that no
# test expects and no line names. A new message comes with its test and
# never with a line here.
