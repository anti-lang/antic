com.example.shapes

Shapes of the plane and what they measure.

Every length is a whole number of UNIT, so a measurement never carries a fraction. The module holds:

  • Circle, the one shape with a body
  • Figure, the variant a drawing stores
let c = shapes.Circle { radius: 2, stroke: shapes.Stroke.Solid };
let a = shapes.area(c);

The rules of the plane stand in the handbook.

Internals

The module is one file. helper and Canvas.secret are the two items no reader of the library sees.

Stroke

pub enum Stroke: byte

How an outline is drawn.

  • Solid = 0

    A line with no gaps.

  • Dashed = 1

    A line with gaps.

UNIT

pub const UNIT: int = 1

The unit every length is written in.

Circle

pub struct Circle

A circle, named by its radius.

  • radius: int

    The radius, in whole units of UNIT.

  • stroke: Stroke

    How the outline is drawn.

Figure

pub variant Figure

Either of the two figures a drawing stores.

  • Round { radius: int }
  • Empty

Canvas

A drawing that counts the shapes put on it.

  • pub name: str

  • protected count: int

    How many shapes stand on it.

  • private_note: int

    A canvas with a name.

  • pub fn add(self, shape: Circle)

    Put shape on the canvas.

  • pub fn size(self) -> int

    How many shapes stand on the canvas.

  • fn secret(self) -> int

area

pub fn area(c: Circle) -> int

The area of c, rounded down.

Internals

The area is four times the radius, which is close enough for the test and wrong everywhere else.
