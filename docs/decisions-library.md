# Decisions of the library reader

Decisions made while fixing the library reader, `src/antic/antl.c`, in steps 4 and 5 of the fix steps of `docs/audit/summary.md`. A later step folds them into `docs/decisions.md`.

- [provisional] A member of a class body read from a library file takes `self` when the first parameter of its function type is `*C`, where `C` is the class. The file does not record the mark. The reader refuses a member whose type is not a function, a bound function type, and one whose parameter count differs from the names the declaration wrote plus `self` plus the out pointer of `may fail`. Reason: the reader used to set `self` on every member, and the `get` of a singleton takes none, so the mark has to come from somewhere. The type is the one source that needs no change of the format. A function of a class body that takes no `self` and whose first parameter is `*C` reads as one that takes `self`. A flag in the marks byte of the member removes that case, with a new format version.
- [provisional] A text constant read from a library file has the type `str` or `[]u8`. Reason: those are the types the checker gives a text literal and a bytes literal.
- [provisional] Every field of a simd aggregate of the IR is a lane: no bitfield, and not the unit break `_`. Reason: the checker makes each field of a `simd struct` a whole lane, and layout divides by the bytes of the lanes.
- [provisional] The tables of a library file nest at most 256 levels deep. That covers the structs, tuples and variants of the type table and the aggregates and the symbolic values of the IR. The reader refuses a deeper file, whether its entries point forward or back. Reason: the reader follows a forward index by recursion. The checker, the layout and the passes walk the nesting by recursion after it. No specification bounds the nesting. 256 levels is far above any struct written by hand. The walks stay a small part of the stack of 1 MB that Windows gives antic.
- [provisional] The unit of a bitfield is the integer of 1, 2, 4 or 8 bytes that holds its bits. A unit larger than its aggregate is an error from the back end. Only a packed aggregate of 3, 5, 6 or 7 bytes has one, such as `packed struct P { a: u32 : 20 }`. Reason: the unit moved back to end inside the aggregate would start before it. The load and store lowering reads one integer, as the entry on a bitfield of more than 8 bytes gives. Two accesses would lift the limit and change the lowering. Made in step 6.
- [provisional] The size of an aggregate in bits fits 64 bits, and the back end refuses a larger one with its name and the target. Reason: the offset of a bitfield and the sum of an offset and a size are held in 64 bits. A larger size wrapped to a small one. Made in step 6.
- [provisional] A symbolic `sdiv` or `srem` of the least value of its type by -1 is an error of the fold, from source and from a library file. Reason: the checker refuses the pair for constants, and the fold computed it in C, where it is undefined. Made in step 6.
