# The fixes of T216 and T215, two more names the compiler writes

Both defects came out of the step of T209, each with a matrix program and
three lines of `tests/known-failures.txt`. Eddie's direction of 2026-11-09
is the Mac alone, so the VMs were not touched.

## Commits

- `abf117bc` fixes T216.
- `0f5fbe9f` fixes T215 by Eddie's choice (a) of 2026-11-09.
- This report, with the two commits in the rows and the times in
  `CLAUDE.md`.

## T216, a nested class named as an interface field

Before the fix the program stopped with `Illegal instruction` in dev mode
and `SIGTRAP` in the other two, as the row says. The sub-object of
`implements s: Shape` and a class `s` nested in `Circle` both took
`Circle.s.descriptor:written` and `Circle.s.table:written`.

A part of the sub-object of the field `s` is now `Circle.s:<part>`: its
table, its descriptor, the thunks of its table, `Circle.s:area.thunk`, and
the thunks of a body qualified by an interface. A nested type keeps
`Circle.s`, and its parts follow a dot, so the two cannot meet.
`lower_sub_object` of `src/antic/lower_desc.c` writes the prefix, and
`LOWER_SUB_PART` of `src/antic/lower_lowerer.h` holds the mark, under a new
`DESIGN:` comment. An export class keeps the C names it exports,
`Circle_dr_table` and the descriptor beside it, and the C header does not
change. No `DESIGN:` comment changed.

## T215, the function of the pattern literals

Before the fix opt refused the program with `invalid redefinition of
function '<module>.patterns.start'`. The `DESIGN:` comment of
`IR_PATTERNS_START` said that a dot kept the name apart, and a function
`start` of a class `patterns` has the same symbol. The fix changed that
comment and a `[provisional]` entry, so it waited for Eddie, who chose
option (a): `patterns.start:written`.

- `IR_WRITTEN` of `src/antic/ir.h` now holds the mark `:written`, and
  `LOWER_WRITTEN` is defined as it, so the mark has one spelling. The
  `DESIGN:` comment of `IR_PATTERNS_START` gives the true reason: no program
  spells the mark.
- The entry of `docs/decisions.md` names `patterns.start:written`, records
  that Eddie chose it on 2026-11-09 and lost its `[provisional]` tag.
