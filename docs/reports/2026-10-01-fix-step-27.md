# Fix step 27, anti interface to antic

Step 27 of "Fix steps" in `docs/audit/summary.md`: M02 and the minor
crossings of `notice.h` and `userdirs.c`. `src/antic/antic.h` is now the
interface `anti` uses beside `driver.h` and the shared helpers.
`src/antic/antic.c` and `src/antic/docpage.c` run the walks behind it.
Logs are in `build/drive/logs/s27-*`.

Status: green and pushed.

## Findings

| ID | Result |
|---|---|
| M02 | Fixed. No file of `src/anti/` includes `lexer.h`, `diagnostic.h`, `parser.h`, `ast.h`, `sema.h`, `types.h`, `header.h`, `ir.h`, `antl.h` or `linker.h`. `units.c` and `check.c` read imports, tests, fixtures and doc comments through `antic_outline`. `fmt.c` lexes through `antic_tokens` and asks `token_is_builtin_type` of the lexer, which the parser calls too, in place of the order of `lexer.h`. `bindtype.c` calls `antic_is_identifier`. `deps.c` and `build.c` read a package header with `antic_library_header`. `doc.c` renders a `struct doc_page` that `antic_doc_page` builds, and owns no memory pool, type table or IR module. `driver.h` no longer includes `linker.h`. |
| `notice.h`, minor | Fixed. It takes `struct package` from `antic.h` in place of `sema.h`. |
| `userdirs.c`, minor | Fixed. It takes `RUNTIME_LIB_DIR` from `antic.h` in place of `linker.h`. |

## Tests first

`anti_interface` (`tests/run_anti_interface.cmake`) refuses a header of
`src/antic/` in `src/anti/` outside `driver.h`, `antic.h` and the helpers,
a header of a pass in `driver.h`, `antic.h` or a helper, and a call of
`driver_interface` from `anti`. Before the change it listed 28 includes in
11 files, `driver.h` including `linker.h`, `notice.h` including `sema.h`,
`userdirs.c` including `linker.h` and the call in `doc.c`
(`s27-red-interface.log`). It passes after it. `tests/unit/test_interface.c`
checks the outline of a source with its doc comments in order, the
identifiers, the range of the type words and library headers of no bytes
and of junk. `anti_doc`, `anti_check`, `anti_fmt`, `fmt_canonical`, the
`anti_bind` tests and the `anti_build` tests pass unchanged
(`s27-targeted.log`).

## Decisions

One `[provisional]` entry under "Repository layout" in
`docs/decisions.md`: `anti` reaches antic through `driver.h`, `antic.h` and
the named helpers alone. The token list of `lexer.h` is part of the
interface, because `anti fmt` works on the tokens of the language and a
second list of them would drift. `docs/notes/doc.md` and
`docs/notes/generics.md` name the new places of the collectors.
