# Fix step 37: test runners

Step 37 of "Fix steps" in `docs/audit/summary.md`: M59, M60, M61 and M62,
from `docs/audit/tests.md`. The logs lie in `build/drive/logs/s37-*.log`.

## Findings

| Id | Result |
|---|---|
| M59 | Fixed, `057e2d0` |
| M60 | Fixed, `36605b3` |
| M61 | Fixed, `6c8da2d` |
| M62 | Fixed, `6c8da2d` |

M59. `run_modules.cmake`, `run_dev.cmake`, `run_trace.cmake` and
`run_anti_build.cmake` take `OBJECT` from `anti_object` of
`tests/CMakeLists.txt`, and the sixteen skips of Windows are gone. With
the skips gone and the old scripts, the Windows VM failed 18 tests on
`could not open 'store.o'` (`s37-win-m59-red.log`). That count includes
`inherits_modules_dev` and `owned_modules_dev`, which had no skip. With the
fix all 100 tests of the dev modules, trace, conf and inject pass there
(`s37-win-m59-green.log`).

M60. `tests/run_native_pin.cmake` is the one check of the five pins and
searches every literal with `string(FIND)`. The five scripts are gone. The
old PCRE2 check refused a recipe holding `10x48` as a copy of `10.48`
(`s37-m60-old-pattern.log`). `native_pin_self` runs the check over a
made-up library and failed before the runner existed
(`s37-m60-self-red.log`). The JIT check reads `pcre2-files.cmake`, which
holds the definitions. `run_pin.cmake` searches the CMake version as a
literal too.

M61. `antic_program` and `program_expect` of `tests/program_output.cmake`
build and run every program that must stop. `run_trap.cmake` replaces
`run_parallel_size` and `run_pattern_limit`, with the messages in
`traps/*.err`. With an antic that prints a warning, the old `run_table`
passed and the new one fails. With a program that prints the message and
exits with 1, the old `run_parallel_size` passed and `run_trap` fails
(`s37-m61-old-runners.log`).

M62. Every runner reads a program it built through `program_expect` or
`program_output`, from files, 19 runners and `run_program.cmake` among
them. `raw_output` refuses a call that reads a program into a variable. It
lists 35 calls of the previous tree (`s37-m62-lint-red.log`) and runs
`program_expect` over a child that writes a CRLF where an LF is expected.
On Windows, `file(WRITE)` writes a line feed as a CRLF, so the test writes
its inputs with `file(CONFIGURE ... NEWLINE_STYLE)`.

## Provisional entries

- Under "Program entry", after the raw-bytes rule: the scripts read the
  standard error of a program through a file as well. `raw_output`
  refuses a program read into a variable. A test of a program that must
  stop wants an abort, `Subprocess aborted` on POSIX and `0xc0000409` on
  Windows.

## Other hosts

The Windows VM passes the converted runners and all 399 `program_`,
`std_`, `abi_` and `clib_` tests (`s37-win-t2.log`,
`s37-win-programs.log`). `memory_checks` fails there at line 38 of its
script, where the host build with `--memory-checks` is refused on
windows-arm64 before the script prints `SKIP:`. The Linux VM passes 128 of
130 (`s37-linux-t1.log`). `memory_checks` and `memory_checks_list` fail
there as antic links, on `_Unwind_Backtrace` missing from
`libclang_rt.asan.a` of `linux-arm64-glibc`. Neither failure is in code
this step changed.
