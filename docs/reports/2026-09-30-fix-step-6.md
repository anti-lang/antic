# Fix step 6: antic checker, types and copies

M36, from `docs/audit/front-end.md`. The logs lie in
`build/drive/logs/s6-*.log`.

S11. A type nested in a refused generic class takes nothing from it.
The unit test segfaulted before the fix (`s6-unit-s11-red.log`).

S06. `types_nest` in `types.c` replaces `types_find_cycle` and
`types_break_cycles`. It measures each struct once, recurses no deeper
than `TYPES_NEST_MAX` and gives the closing field the type error. The
checker refuses values that nest deeper than 256 levels, and the reader
of a library file measures its type table with the same walk. The limit
bounds every later walk over fields as well, which a worklist in one
walk would not. The constants' walk of a long chain moves to
`sema_chain.c`, and `type` lines and `constraint` sets use it. Each type
records its depth, and a type that `type` lines or copies nest deeper
than 256 levels is refused where it is made. Before the fix, chains of
20000 structs were accepted (`s6-unit-s06-red.log`), 30000 `type` lines
segfaulted (`s6-unit-alias-red.log`) and 100000 constraint sets
segfaulted. All three now pass or are refused.

S07. `fill_one` checks the base chain of every copy and the nesting of
every copy without type parameters. A struct that holds a copy not
filled yet keeps no height, so a cycle is found when its last copy is
filled. The finding's pair of generics segfaulted
(`s6-unit-s07-red.log`). `class A<T> inherits A<int>` looped, and so did
`class A<T> inherits B<T>` with `class B<T> inherits A<T>`, which the
finding did not name and which the check of the base of every copy
closes. Without the open state, the test of a cycle that closes late
crashes. The check made `sema_has_params` walk every path through a
doubling chain of copies, and that walk now keeps a record too.

M34. No copy is filled after a refusal. A module names at most 16384
copies of types and 16384 of functions. A chain of function copies past
64 is refused, and so is a function copy whose name passes 65536
bytes. A cut name inside a finite chain of type copies was accepted,
while a symbol spells the arguments in full. It is now refused when the
chain ends. The largest module of the suite names 259 copies of types
and 87 of functions. `errors/copies_deep.anti` and
`errors/copies_many.anti` cover the copies of functions, whose second
case hung before the fix (`s6-copies_many-red.log`).

M36. `literal_complete`, the search for a promoted name, `fixed_layout`
and `depends_on` keep a record for one question. The finding's forty
classes also reached `sema_needs_teardown`, `sema_holds_mutex`,
`type_pointer_free`, `holds_class`, `holds_union`, `holds_concurrent`,
the default `==` and the lists of the calls of the default `==` and hash,
and each of them keeps a record as well. The set and the map of pointers
move to `ptrset.c`, so `types.c` shares them and `sema_copies.c` drops
its copy of the map. Before the fix, the unit tests hung on the forty
classes and on sixteen damaged libraries that import each other
(`s6-unit-m36-red.log`, `s6-unit-imports-red.log`).

## Seen in passing and left

- The module scope is searched linearly, so 100000 items take 16 s to
  check. The chain tests keep to 30000 links for that reason.
- A type built from tuples that `type` lines share, such as
  `type Q0 = (Q1, Q1);`, has a name that doubles per level. Printing it
  and walking the parts of a tuple still go down every path.
- A diagnostic is cut at a fixed length. The message on `v as S40`
  ends after the size of `S40`.
- Lowering `==` on a struct that holds another twice writes one
  comparison per leaf of the value.
- A chain of `let` statements that each take the address of the one
  before builds a pointer type of any depth.

## Provisional entries

- The values of a struct, union, class or variant nest at most 256
  levels, arrays, tuples and `?T` included, in the source and in a
  library file.
- A chain of `type` lines and one of `constraint` sets is taken apart
  as a chain of constants is, and nests at most 64 resolutions.
- A type nests at most 256 levels above the names in it.
- A copy of a generic is checked when it is filled.
- A cut name inside a chain of copies is refused when the chain ends,
  and so is a function copy whose name passes 65536 bytes.
- A module names at most 16384 copies of types and of functions, and a
  chain of function copies deeper than 64 is refused.
