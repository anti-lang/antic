- Defect 11: curl follows no redirect. anti reads the target from the
  answer and holds it to the rule of a repository URL, ten redirects at
  most. The three cases `redirect_*` put a curl of their own first on
  the path, a shell script, so Windows runs none of them.
- Defect 9: the lock records `needs`, the packages each version needs. A
  lock answers only when the manifest reaches every package of it through
  them. A lock written before the field walks once.
- Defects 1 and 10: `options_key` and `imports_key` of `src/anti/build.c`.
  The imports reach the key of a dev object as well. The IR holds no
  sizes, so a struct of an import that grew left the library file of its
  user the same bytes and its object with the old layout. The case
  `cache_import_layout` shows it. `anti_build` took 2.87 s alone before
  and after.
- The new runner `tests/run_anti_build_cases.cmake` holds 17 cases, each
  named `anti_build_<case>`. Three new message cases stand in
  `tests/anti-build/messages.cmake`.
- `30ca48ab` records the commits in `docs/audit/anti-tool.md`,
  `docs/audit/summary.md` and `docs/audit/tests-findings.md`.
