## Items

- 1, T365. The text of a signature names an enum by its qualified name, so the text of `reflect.call` and that of the structural hash are one, and the two spellings of `lower_desc.c` are gone. Lowering writes the descriptor of each enum a text names. The pass over the whole program reads the base and the values of each enum from those descriptors. It writes a trampoline per text that compares each enum argument, narrowed to its base, with the values, and a number that the enum does not declare gives `WRONG_KIND`. `std_reflect_call_enum` passes. `std_reflect_call_enum_signed` takes an enum over `i16`, and `modules_reflect_enum` calls a function of a library with an enum of the library in both modes.
- 2, T377. A part of the literal of a `let` that is a capturing `snapshot fn` takes the type `own fn`. So does a part of a literal inside it. The snapshot goes on the heap with its texts, and the teardown of the local frees it. An array gives every element that type when one of them is such a snapshot, since its elements have one type. The three tests of T377 pass. Three new matrix programs hold the frees on every exit, the text of an array local and the text of a name a `let` takes from a tuple.
- 3. No code. `matrix_closures_snapshot_of_a_tuple_part_given_by_assignment_refused` holds the refusal of `=` for a name a `let` takes from a tuple, which item 2 makes an owner.
