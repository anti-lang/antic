# Fix step 20, the minor findings of the runtime

Branch `fix/mrt`. Logs are under `build/drive/logs/`, named `s20rt-*`.
The minor findings carry no IDs, so each is named by its rule and the
place the summary gives it.

## Findings

- Rule 1, `object.c:612`. Fixed. `anti_rt_entry_body` and
  `anti_rt_body_entry` of `object.c` convert every table entry, and
  `hooks.c`, `registry.c` and `plugin.c` call them.
- Rule 3, `registry.c:451`. Not a defect any more. Step 13 (`fd0afd8`)
  removed the read of an address and a length that held the conversion.
- Rule 9, `conf.c:489`. Fixed. Every `snprintf` of `src/rt/` checks its
  result: the configuration formats into memory of the exact size,
  `plugin.c` marks a cut reason with `...`, `trace.c` and `toml.c` fail
  on a line that does not fit, and `digest.c` writes hex without a format.
- Rule 10, `conf.c:416`. Fixed. The file layer reads keys and values by
  their length, and `anti_rt_conf_get` gives the length the key keeps.
  `threads.c:120` had been fixed by step 11.
- Rule 11, `object.h:213`. Fixed. The nine comments name the call that
  frees.
- Rule 12, `plugin.c:433`. Fixed. One close in `anti_rt_plugin_load`, and
  one release per name in `anti_rt_fs_rename` and `anti_rt_fs_list`.
- Rule 13, `sync.c:78`. Fixed. `anti_rt_fail_exit`, `anti_rt_fail_abort`
  and `anti_rt_note` of `assert.c`. No other file of `src/rt/` writes to
  standard error or aborts.
- Rule 14, `trace.c:228`. Fixed. The slide walk checks each command
  against `sizeofcmds`.
- Rule 14, `conf.c:750`. Fixed. `rt.configure` refuses a path with a NUL
  byte, and the file layer a value with one.
- Rule 20, `digest.c:79`. Fixed for `src/rt/`: the three SHA-256 pieces
  and `registry_find` are static.
- Rule 21, `std.h:107`. Fixed. The guard closes the header. The runtime
  part of `cpu.h:9` is fixed too: `hooks.h` drops `std.h`, and `object.h`
  includes `<stddef.h>`.
- Rule 23, `conf.c:69` and `init.c:3`. Fixed. `ready` is atomic, and the
  configuration state says why it needs no lock. `loaded.c:26` had been
  fixed by step 12.
- Rule 26, `cpu.c:307` and `start.c:159`. Fixed. Left: `file_bytes`,
  `index_bytes` and `same_bytes`, which the summary gives to the session
  of code both sides write.
- Rule 27, `assert.c:19`. Fixed. `signal.c:6` had been fixed before.
- Rule 25 is the renaming step. The rule 18 splits are step 21.
