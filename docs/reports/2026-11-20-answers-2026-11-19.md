## Items

- Items 1, 2, 4 to 13, 15 to 20, B, C and E to J are built.
- Item 3 needs no code: `matrix/ownership_take_of_an_own_function_field`
  holds the refusal. Item 21 changed the provisional entry of R187.
- Item 14 needs no code. `anti symbols` splits a text of `plugins` at
  `:`, the separator of the runtime of macOS, as it did. The case of the
  list commit became one that holds that split.
- A stopped. `serialize` writes from the descriptor, which holds the
  class name and no module path. The registry knows the module, but by
  its DESIGN in `src/rt/registry.h` the compiler writes it only into a
  program that reaches reflection or `deserialize`. `module.Class` then
  needs a field of the descriptor, which changes every class descriptor
  and the layout that the runtime shares, or a registry in every program
  that serializes, which changes that DESIGN. Both are more than the
  rewrite of the pinned JSON outputs that A allowed, so no pinned output
  changed.
- D stopped. The DESIGN of `convert_in_place` in `src/antic/lower_stmt.c`
  says that the handler yields a value of the type of the call and that
  the slot moves to the sub-object of an interface once every path has
  left its value there. A handler that yields any `?*Base` or
  `?*Counter` breaks that for an interface, since a pointer it yields
  cannot move again. D needs that DESIGN rewritten, and only the DESIGN
  of `check_handled` was cleared.
