## Findings closed

Each check was first shown to pass on a broken input, and each fix
comes with a test that feeds the check such an input.

- S335, `06d0f6b6`. The runner searched the assembly for
  `DEBUG_S_SYMBOLS` and `S_LPROC32`, spellings of the native back end,
  so it passed whatever antic wrote, `s15-s335-old.log`. It reads the
  dev object with `llvm-readobj --codeview` now, and
  `codeview_empty_refuses_<target>` assembles an object with an empty
  subsection of symbols.
- M319, five parts.
  - `718b75d2`. `llvm_coff_plugin_*` printed `SKIP:` without
    `SKIP_REGULAR_EXPRESSION`, so a skip counted as a pass. The new test
    `skips_registered` reads every test from `ctest --show-only` and
    refuses such a registration. It found the same gap at the clib cases
    and `memory_checks_list_macos-x86_64`, `s15-m319-guard-red.log`.
  - `8ddb9cda`. `package_keys` and `debug_info` were registered only
    when their sysroots or a debugger were found. The first now fails
    naming the missing sysroots, as `program_abi_raymath` fails without
    raylib, and the second skips with its reason,
    `s15-m319-list-before.log` and `s15-m319-list-after.log`.
  - `d5cb6dce`. `macos_sdk` skipped for every refusal of the SDK
    script, a changed SDK among them. It skips for a missing SDK alone,
    and `macos_sdk_runner` holds both cases.
  - `e3e89ef2`. `release_dry_run` skipped when a fixture did not compile
    or link. It fails with the output, and `release_dry_run_runner`
    holds three stand-ins that refuse one fixture each.
- M320, five checks.
  - `2936609e`. The wrong-signature cases of `manifest_signature` and
    `installer_github` passed for an installer that accepts every
    signature, `s15-m320-old-*.log`. The manifest stays right, a
    signature of another manifest stands in, the message of the refusal
    is matched, and a copy of the installer without the check must
    install from the same files.
  - `3362bafc`. `run_probe.cmake` read no exit status.
    `abi_probe_runner` gives it two probes that end with 3.
  - `00fc93e9`. `fmt_canonical` passed a run that a signal ended.
    `fmt_canonical_runner` gives it such an anti.
  - `54ab226f`. `llvm_verify` skipped a crash. A skip needs status 1 of
    both runs, and the runner names the four files that are no program.
    `llvm_verify_runner` holds both faults.
  - `a99dedcc`. `run_anti_build.cmake` took an empty build id.
    `read_build_id` of the new `tests/build_id.cmake` demands one line
    of 64 digits for both runners, and `build_id_reader` tests it.
- M369, `c3e7267b`. `script_policies` read the `-P` calls of two files
  and took any version. It reads the build files, the recipes, the
  runners, the tools and `README.md`, and asks for the version of the
  root. Four runners got the line, and fourteen scripts went from 3.20
  to 3.21, which closes the minor finding on CMake 3.20 as well.
  `script_policies_runner` holds a script without the line, one of 3.20

- M370, `b0b90de3`. `one_allocator` took a hand list of programs and

  `antic_core` or `anti_core`. The test then failed on
