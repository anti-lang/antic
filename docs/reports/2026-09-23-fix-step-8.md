# Fix step 8: lowering, linking and printing

Step 8 of "Fix steps" in `docs/audit/summary.md` closes S22, S23, S24 and
S25 in `linker.c`, `lower.c`, `whole.c` and `ir_print.c`. Each fix began
with a test that failed.

## Findings

| ID | Result | Test that failed first |
|---|---|---|
| S22 | fixed | `shared` in `tests/unit/test_link.c` refuses a command string that holds `(null)` |
| S23 | fixed | `tests/programs/by_unsigned.anti` looped without end and hit its timeout |
| S24 | fixed | `checks_provided_interfaces` in `tests/unit/test_whole.c` |
| S25 | fixed | `function_reloc` in `tests/unit/test_ir.c` crashed |

- S22. The `-L` of the C library is now built inside the branch of the
  platform linker. That branch is the only one that reads the string, and
  the only one where `crt_dir` is set.
- S23. An unsigned range now always walks up, because the checker refuses a
  negative step on one. Its test compares unsigned. The magnitude of a step
  is negated in `uint64_t`. The new program checks a step of 2^63 on a
  `u64`, a `u64` range across 2^63, a `u8` range across 128 and a signed
  step of -2^63.
- S24. `chain_of` requires an address and a length in the version record.
  The global it names must hold an array of at least that many integers,
  and the length must be above zero. The field count and the version length
  must be integers, and the size an integer or a symbolic value. The version
  length must not pass its bytes. A damaged descriptor is reported as
  "the library file that describes it is damaged". The reader already
  bounds every address of a library file (`remap_const` in `antl.c`). So
  the test damages the chain by pointing it at a global of bytes, not at an
  index past the table.
- S25. The printer looks a relocation with `fn` set up among the functions.

## Left open

- A signed range whose span passes 2^63, such as `-2^63..1 by -2^63`, still
  computes `high - low` in signed arithmetic, and the range comes out empty.
  An upward counter that steps past the largest value of its type also
  wraps. S23 covers neither, and no finding names them. They belong in a
  later audit entry.
