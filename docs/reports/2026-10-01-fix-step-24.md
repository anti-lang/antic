# Fix step 24, antic driver

Step 24 of "Fix steps" in `docs/audit/summary.md`: M17 and M21. The fix
changed `src/antic/driver.c` and `src/antic/linker.c`, with
`src/antic/linker.h`. `src/rt/toml.c` moved from the sources of `anti`
into `antic_core` in `tools/sources.cmake`. Logs are in
`build/drive/logs/s24-*`.

Status: green and pushed.

## Findings

| ID | Result |
|---|---|
| M17 | Fixed. `link_inputs_of` of `driver.c` fills the inputs of every link: a program, a library for C, a plugin and the join of a bundled runtime. A shared library now takes the frameworks, the libraries of `link linux`, the glibc mode and the memory checks. `link_shared_command` links a Linux library of the glibc mode against the glibc sysroot and runtime, and links the runtime of AddressSanitizer on macOS and Windows. `glibc_libraries`, `macos_memcheck` and `windows_memcheck` are each one owner for a program and a library. The flavours of lld and the marker file of each sysroot come from `link_lld_flavour` and `link_sysroot_marker` of `linker.c`, whose link lines name the same files. |
| M21 | Fixed. `index_others` reads `anti-plugins.toml` with `src/rt/toml.c`, the reader of the runtime, and `index_string` writes each value in the quotes that reader reads back. The `strstr` scan is gone. |

## Tests first

`shared_inputs`, a new test, builds a shared library of each case and
reads the result with the pinned `llvm-objdump` and `llvm-readobj`.
Before the fix the macOS library of `--framework CoreFoundation` failed
with `undefined symbol: _CFAbsoluteTimeGetCurrent` (`s24-red1.log`). The
Linux library of `--linux-lib X11` named no library (`s24-red2.log`).
The `--memory-checks` libraries of macOS and windows-x86_64 failed with
`undefined symbol: __asan_loadN` (`s24-red3.log`). The unit tests
`shared_modes` and `sysroot_names` of `test_link.c` pin the command lines
and the names. They did not compile before `link_lld_flavour` and
`link_sysroot_marker` existed.

`plugin_host` writes an index with CRLF line ends, a comment and strings
in double quotes. It also holds a stale entry of the library and a path
with a single quote. Before the fix the rewritten index held the new entry alone
(`s24-red4.log`). After it the other entries stay, the stale one goes and
the program finds the library through the index. A second case is an
index cut off inside an entry, which antic replaces.

## Decisions

Two `[provisional]` entries in `docs/decisions.md`:

- under "Plugins", antic reads the index with `src/rt/toml.c` and writes
  the entries of other libraries back in its own form. A key of another
  name and a comment go, and a name with both quotes or a line break is
  refused.
- under the memory checks of round five, a shared library takes the link
  facts of a program of its module. A Linux one leaves the runtime of
  AddressSanitizer to the program that loads it.
