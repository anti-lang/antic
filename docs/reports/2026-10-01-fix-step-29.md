# Fix step 29, anti copies that drifted

Step 29 of "Fix steps" in `docs/audit/summary.md`: M23, M24, M25, M26
and the minor names spelled twice. M25 takes one constant for the
include limit and one message in both walks. Logs are in
`build/drive/logs/s29-*`.

Status: green and pushed.

## Findings

| ID | Result |
|---|---|
| M23 | Fixed. `unit_options` of `src/anti/units.c` fills the options every compile of `anti check`, `anti build`, `anti test` and `anti doc` starts from: the roots, the runtime, the target and level, and the package name. `unit_host` gives the host target with one message, so `check.c` and `test.c` no longer call `exit(2)`. `anti test` and `anti doc` read the package name from `anti.toml`. |
| M24 | Fixed. `src/rt/license.h` holds the two markers, the head of the `build` line and the length of an id. `src/antic/notice.h`, `license.c`, `trace.c`, `symmap.c` and `syms.c` include it. `symmap_notice` is the one reader of the id in anti, and `anti build` and `anti symbols` call it. The `# build` line of a map stands once in `symmap.h`. |
| M25 | Fixed, as Eddie decided. The walks stay apart. `src/rt/conf_include.h` holds the bound, 32 files above a file, and the message of a cycle, which `conf.c` and `syms.c` both use. |
| M26 | Fixed. The header takes the last segment of the module path from the package header of the library file, which the DESIGN comment of `bind_header` already said. `deps_library_header` of `deps.c` is now the one reader of that header in anti, and `build.c` and `bind.c` call it as well. |
| Names spelled twice | Fixed. `anti-plugins.toml` stands in `src/rt/plugin_index.h`, which `target.h`, `plugin.c` and `syms.c` include. `-symbols.zip` stands in `syms.h`, and `bindclang.c` takes `RUNTIME_SYSROOT_DIR`. |

## Tests first

- M23: `anti_internal` drives check, both build modes, test and doc over
  `tests/anti-build/internal`, where `app` uses an internal item of
  `core`. Before the fix the dev build, the release build, `anti test`
  and `anti doc` refused it with "`core` has no public item `tuning`"
  (`s29-red-internal.log`). It passes after the fix
  (`s29-green-internal.log`).
- M24: `build_id_of_notice` of `test_syms.c` reads a program that has a
  line of the form before its notice. Before the fix it got the wrong id
  and took a decoy with no notice (`s29-red-buildid.log`).
  `runtime_markers` of `test_link.c` refuses a marker spelled in a file
  that writes or reads the notice.
- M25: `conf_include_depth` runs a program and `anti symbols inventory`
  over chains of 33 and 34 files. Before the fix the inventory refused
  both at `c32.toml` with "includes itself" (`s29-red-depth.log`).
- M26: the `header` case of `anti_bind_header` binds a copy of
  `geo.antl` named `other.antl`. On Windows it also binds it by its
  native path. Before the fix it wrote `other.h` (`s29-red-bind.log`).
- Names: `names_once` refuses a second spelling of these names in
  `src/`. Run over the tree before the change, it named six sites
  (`s29-red-names.log`).

Not changed: the cache key of a library file of `anti build` names
neither the package name nor the version. A renamed `[package]` keeps a
library file of the old name until its source changes. The audit did not
name this, and it is left for a later step.

## Decisions

Four `[provisional]` entries in `docs/decisions.md`:

- under "The build command": every compile of the four commands carries
  the package name, through `unit_options`;
- under "The bind command": `anti bind --header` names the header after
  the module;
- under "Names and shared code of the runtime": `src/rt/license.h` and
  the one notice reader;
- under the same heading: `plugin_index.h`, the suffix in `syms.h`, the
  sysroot directory and the test `names_once`.

M25 follows Eddie's entry of 2026-09-30. `docs/notes/symbols.md` names
the shared header.
