## Choices

- The value that the job copies. The answer names a local class value
  with an `own` field. The fix copies every value that
  `sema_reads_existing` reads, if its type needs a teardown by
  `sema_needs_teardown`. That covers a name, a field, an element, `*p` and
  an `as` to its own type. A class with a `destruct` and no `own` field is
  copied as well, since `=` refuses to copy it. In each of these the byte
  copy reached what the caller tore down, as in T382.
  `sema_reads_existing` moved from `sema_checker.h` to `sema.h` for
  lowering.
- The grammar of the delimiter row. The row holds at least one `|`, and
  the `|` split it into cells. An empty first or last cell stands for a
  leading or a trailing `|`. Each other cell is one or more `-`, with an
  optional `:` before and after them and spaces or tabs around them. The
  row holds at least one such cell. The count of the cells is not
  compared with the line before. That count needs the cells of the first
  line, which escapes and inline code split.
