## Choices

- Item 1. The first spelling of a type in the declaration wins, and a
  name without a module stands bare. The base after `inherits` keeps the
  whole path of its module, by the entry under "The doc command" that
  says so. An `export type` that names a copy of another module is no
  struct name of the source, so it records nothing.

  the reference of its part. A constant index counts when the checker
  evaluates it to a number.
- Item 6. A word that starts with `|` opens markup for the fill, as a `-`
  does.
