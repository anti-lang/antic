# The pin of 23.1.1-anti.8, with llvm-cov

The step `pin` of the test run, on 2026-10-12, on `main`. antic now builds
with clang and the LLVM tools of `23.1.1-anti.8` of `anti-lang/llvm-tools`.
The build installs llvm-cov, and no package carries it.

## What the step added

- `tools/llvm-pin` and `tools/clang-pin` name the tag `23.1.1-anti.8` and
  its twelve digests.
- `SHA256SUMS` and `SHA256SUMS.sig` of the release were downloaded first.
  The signature verifies against `tools/keys/release.pem` with `openssl
  pkeyutl -verify`, in `build/drive/logs/cov-pin-verify.log`. A script
  wrote each digest of the pins from its line of that file.
- `SHA256SUMS` of the release equals `build/dist/SHA256SUMS` of the
  checkout of `anti-lang/llvm-tools` byte for byte.
- `tools/get-llvm.cmake` installs llvm-cov with the tools of this machine.
- `tools/check-llvm.cmake` checks the version of llvm-cov. Its copy into
  the runtime archive leaves llvm-cov out.
- `ANTIC_LLVM_TOOLS` of `tools/pinned-tools.cmake` holds llvm-cov, so the
  test `pinned_tools` checks nine tools.
- The new test `no_llvm_cov_packed` holds decision 29: llvm-cov reaches no
  directory that the packer copies. Its runner is
  `tests/run_no_llvm_cov_packed.cmake`.
- `docs/decisions.md`, `docs/distribution.md`,
  `docs/notes/hosts-and-harness.md` and `docs/toolchain-later.md` name
  anti.8, as the commits of anti.6 and anti.7 changed them. `CLAUDE.md`
  holds the new counts.

`build/deps/llvm-tools` and `build/deps/clang` were removed, and `cmake
--preset host --fresh` downloaded both archives of macos-arm64. Each
passed the digest of the pin, its line of `SHA256SUMS` and the signature,
in `build/drive/logs/pin-configure-host.log`. `VERSION` of both reads
`build 8`. The tools archive of macos-arm64 differs from that of anti.7 in
`VERSION` and `bin/llvm-cov` alone, in
`build/drive/logs/pin-diff-anti7-anti8.log`.

## Where the task and the code differ

- The task says the packer does not take llvm-cov. `tools/pack-anti.cmake`
  copies a whole `bin/` into a package. For this machine that is `bin/` of
  the runtime archive, and for another host it is the directory that
  `tools/get-llvm.cmake -DHOST=<host>` lays out. The tools archive of a
  host holds llvm-cov, so the packer would have carried it for five hosts.
  `tools/get-llvm.cmake -DHOST` now removes llvm-cov from that directory.
  The packer is unchanged.
- `toolchain_pin` runs `tools/check-llvm.cmake` on `bin/` of the runtime
  archive, which holds no llvm-cov. The script takes a new value,
  `RUNTIME_ARCHIVE`, and `toolchain_pin` sets it. With it the script skips
  llvm-cov and refuses one that stands there.
- The task names `build/deps/llvm-tools` as one of two archives to
  download again. That directory holds the tools of the other five hosts,
  which step 1 of `./r` fetches. The tools of this machine stand in
  `build/deps/llvm`. They were installed again without a removal, since
  `.installed` named the digest of anti.7.
- The task says the pin of anti.6 verified the digests this way. The pin
  before this step was anti.7, which did the same.
