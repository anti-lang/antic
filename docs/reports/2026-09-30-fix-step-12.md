# Fix step 12, runtime plugin loader

Step 12 of "Fix steps" in `docs/audit/summary.md`. Files `src/rt/plugin.c`,
`src/rt/plugin.h`, `src/rt/loaded.c`, `tests/unit/plugin_bad.c`,
`tests/unit/test_plugin_table.c`, `tests/run_plugin_versions.cmake` and
`tests/plugin/versions/foreign/`. `src/rt/hooks.c` needed no change: the
`created` hook still counts the object, and the loader's count of a build
stands beside it in `plugin.c`. Logs are in `build/drive/logs/s12-*`.

Status: BLOCKED. Both commits are local and not pushed. The one failing
test is the pin `link_identity_macos-arm64`, and rewriting that pin was
refused by the permission check of the session.

## Findings

| ID | Result |
|---|---|
| S28 | Fixed. `reserve` finds the slot and the entry and counts one object against the slot under one hold of the lock. `built` gives that count back once `init` has run, where the `created` hook counts the object. `instance` and `anti_rt_plugin_provider` both go through the two. `supports` walks the functions under the lock. |
| S33 | Fixed. `class_sound` checks each descriptor of the chain with `descriptor_sound`. The ancestors end in the class, and the parents end after `depth` steps. |
| M47 | Fixed. `matches_host` runs the checks of the interfaces, and `anti_rt_plugin_load` finds the image of the table, before the lock. `anti_rt_plugin_image` ends the program when the calling thread holds the lock of the slots, which a thread-local flag set by `anti_rt_plugin_hold` tells. |
| M58 | Fixed. `rt_plugin_table` loads its library with runtime `9.9.9`, with another chain and with an interface in its own image, and expects each message. `plugin_versions` builds a library against a `Greeter` whose `words` gives an `int`, and the host refuses it. |

## Tests first

- S28, `unload_waits_for_build` in `test_plugin_table.c`. `init` of
  `plugin_bad` calls a function the test sets, which unloads the library.
  Before the fix the unload closed the library in the middle of the build
  (`s12-t1.log`, lines 23 to 25). After the fix it refuses, for
  `instance` and for a provider alike.
- M47. The guard in `anti_rt_plugin_image` ended `rt_plugin_table` at its
  first load, with "the image of an address was asked for under the lock of
  the loaded libraries" (`s12-t3.log`). The fix moved every lookup out.
- S33, `damaged_lists` and `damaged_parents`. Counts of 100000,
  `INT64_MAX` and -1, NULL lists, a bad name, slot and offset, a parent
  that is the class itself, a depth that disagrees and ancestors on the
  heap. All 19 loaded before the fix (`s12-t1.log`).
- M58 is a gap in the tests, so its new tests passed at once. The case of
  another runtime is a unit test. antic writes its own `ANTIC_VERSION`
  into a library, so an antic-built library of another runtime needs another
  antic. A patched library would fail its code signature on macOS.
