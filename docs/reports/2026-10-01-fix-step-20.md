# Fix step 20, the ABI between antic and the runtime

Step 20 of "Fix steps" in `docs/audit/summary.md`: M04 and M06, and the minor
on the place of `Match`. The fix needed a new header and source of
`src/antic/`, `rt_abi.h` and `rt_abi.c`, two new headers of `src/rt/`,
`sync.h` and `threads.h`, and changes to every file of lowering that calls
the runtime, to `whole.c`, `x86_64.c`, `driver.c` and `CMakeLists.txt`. Logs
are in `build/drive/logs/s20-*`.

Status: green and pushed.

## Findings

| ID | Result |
|---|---|
| M04 | Fixed. `RT_FUNCTIONS` of `src/antic/rt_abi.h` lists the 69 runtime functions antic declares, each type as its IR type and its C type. Lowering declares every call from it through `lower_rt_declare` and `lower_rt_call`. `lower_sync_call`, `lower_rt_function`, the parameter arrays at each call and the names spelled at each call are gone. The 25 functions without a prototype have one, in `src/rt/sync.h`, `src/rt/threads.h` and `src/rt/regex.h`. The records stand in the same header, one list per record, and `rt_record_agg` builds each aggregate. |
| M06 | Fixed. `lower_desc.c`, `lower_expr.c` and `whole.c` name every item of a record by its constant of `rt_abi.h`, such as `RT_DESCRIPTOR_FUNCTIONS`, and no file reads a descriptor, a function, a version or a `whole.c` record by a bare number. `DESCRIPTOR_ITEMS` and `struct_agg` are gone. |
| Minor, `src/rt/patterns.c:126` | Fixed. `struct anti_match` and `struct anti_maybe_match` moved into `src/rt/regex.h`, where `types.c` said they stood. |

## Tests first

- `runtime_functions` of `tests/unit/test_lower.c` compiles the C column of
  every row against the prototype in `src/rt/` through `_Generic`. The test
  then links no runtime. It also checks each IR type against its C type. Before
  the fix the unit tests did not build: `sync.h` and the 25 prototypes were
  missing (`s20-red1.log`).
- `runtime_records` lays out every record for the host. It compares the
  offset and the size of each item with the member of the same name. It
  compares the size of the whole with the struct.
- `match_layout` lays out the `anti.lang.Match` a program uses and compares
  it with `struct anti_match`.
- Each test was checked against a table broken on purpose: a parameter of
  `anti_rt_chan_new` made `int32_t`, `size` and `depth` of the descriptor
  swapped, and `floor_length` made `I32`. Every change failed
  (`s20-mut-run.log`), and the table was restored.

## Defects the table found

- `anti_rt_dispatch` and `anti_rt_object_of` were declared to return nothing
  while the runtime returns a pointer, and the call took a pointer.
- `EXPR_ATOMIC` rewrote the result of the shared declaration of an atomic
  at each call, and the singleton `get` declared `anti_rt_atomic_load` and
  `anti_rt_atomic_compare_swap` to return nothing. The declarations now give
  the `int64_t` and `int8_t` of the runtime. A call that wants a pointer
  keeps that type, since the bits are the same.

None changed the emitted code: `emit_identity` passes with the manifest of
step 19.

## Pinned outputs

A record takes the names of the C members. The second item of
`anti.rt.Injectable` is `owner`, and the fourth of `anti.rt.Provides` is
`class_of`. The 15 dumps under `tests/dump/` and `tests/opt/` that print
`anti.rt.Injectable` changed in that one line.

## Notes
