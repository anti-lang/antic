## Tests

- `tests/unit/test_files.c` is new. It reads a directory as a file, which
  failed before the fix, and writes into a missing directory and, on
  Linux, to `/dev/full`. It walks a tree holding an unreadable directory
  and a tree holding a link to its parent. Three checks of the reader and
  both walks failed before the fixes: `build/drive/logs/s17-unit-red.log`.
- `manifest_missing` of `test_deps.c` checks that a failed read leaves no
  allocation, for a missing file and for a file that is no TOML. Both
  checks failed before the fix: `build/drive/logs/s17-unit-red2.log`.
- M16 has no test that fails first. The leaks it names follow a failed
  `malloc`, and `anti` has no way to make one fail. The command tests of
  the suite cover each new function.
