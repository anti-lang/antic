## A defect of antic found on the way

`e78f2d04`. The reader of the generics section of a library file joined a
declaration to its listed symbol only when it was public. An `internal`
generic function made the file of its module read as damaged, and the
build of every module that imports it stopped. `internal_package` now
calls an internal generic across two modules of one package and failed
before (`s40s-red-internal.log`).
