# Fix step 16, anti symbols and zip

Step 16 of "Fix steps" in `docs/audit/summary.md`: S41 for `syms.c`, S42,
M11 and M17 for `zip.c`, in `syms.c`, `symmap.c` and `zip.c`.

## Findings

| ID | Result | Where |
|---|---|---|
| S41 | fixed for `syms.c` | `map_lookup` and `syms_resolve` read with a cursor that takes digits alone and refuses a sign and a value above 64 bits, in place of `sscanf`. Tokens are named by start and length, so the fixed buffers are gone. |
| S42 | fixed | `load_deployment` matches no entry for a unit with no id, so `memcmp` never takes a null pointer. `symmap_write` sorts through `sort_map`, which skips `qsort` for zero functions. |
| M11 | fixed | `inflate` takes the declared size and `emit` refuses output past it, for literals, copies and stored blocks. A copy may not reach back before the entry either. |
| M17 | fixed for `zip.c` | The name of an entry is copied after the check of its data range, and `zip_read` frees everything on failure. `manifest.c` belongs to step 17. |

## Tests

- `test_zip.c` is new and runs in `unit`. It reads every cut of an
  archive and a count above the directory. A directory, a name, a local header
  and entry data point outside the file. Some deflate streams are
  reserved or cut, or copy before any output or into earlier output.
  Others carry a bad stored complement, an oversubscribed code, a short
  length or a wrong CRC. A stream of 2 MB declared as 10 bytes and a stored block past its size
  stop at the size. Before the fix, M11 and the reach-back checks failed
  and every failed read left its bytes behind
  (`build/drive/logs/s16-unit1.log`).
- `anti_symbols_input`, new. The map has lines of 21 and 32 hex digits.
  The trace has a frame offset of 21 digits, a signed offset and a module
  number above 64 bits. Before the fix every frame resolved to the line
  the clamped value claimed (`build/drive/logs/s16-symin1.log`).
- `unit`, `tests/unit/test_syms.c`, new: an index unit with no id beside
  the entry `/prog.map`, and the map of a file with no function. Both
  passed before the fix on this Mac, in the UBSan build too
  (`build/drive/logs/s16-ubsan-unit4.log`). The macOS headers do not
  mark `memcmp` or `qsort` nonnull, so the sanitizer does not see the
  call. The tests take the paths for a host whose C library does.

## Gates

## Decisions

Four `[provisional]` entries stand under "Step 16" in
`docs/decisions-tool.md`. `zip_read` empties its output on failure.
Deflate stops at the declared size and before the entry. Map and trace
numbers are digits alone, and a line out of range is refused. A unit
without an id matches no entry.
