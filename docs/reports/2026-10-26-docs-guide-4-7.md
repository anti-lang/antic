## Questions answered from the code

- Does a dev build trap on the end of a `switch` that names every value? No. The block is `unreachable` and holds no instruction, and `n as Dir` is the check that keeps the fact true.
- What does a release build make of that block? The test of the last arm becomes `llvm.assume`.
- Does `x in lo..hi` evaluate `hi` always? No. It is the `&&` of two comparisons, so `hi` runs only when `x` reaches `lo`, as "Small things" decides.
- Is `as ?*T` refused by R058? No. `?*` is one token, and the provisional entry on R058 keeps the conversion.
- Does a release build refuse the warning `never-fails` of a function that keeps the form of a failing one? Yes, and its code returns a null error on every path, which each caller tests.
