# Fix step 14, anti repository inputs

Step 14 of "Fix steps" in `docs/audit/summary.md`: S45, S40, M12, M13 and
M14 in `repo.c`, `deps.c`, `sdk.c` and `doc.c`. Each fix followed a test
that failed first.

## Findings

| ID | Result | Where |
|---|---|---|
| S45 | fixed | `repo_index` and `repo_module` refuse a name, version, module path or digest that is not of its form. `deps.c` checks the index and the lock on read. `sdk_export` refuses a `Version` that is not digits and dots. |
| S40 | fixed | `version_part` bounds each part in `int64_t`. `deps_version_valid` takes one to three parts of at most nine digits, and an invalid version or constraint satisfies nothing. |
| M12 | fixed | `is_loopback` refuses an authority with an `@` and takes a port of digits alone. |
| M13 | fixed | The index and the lock are checked on read. `lock_write` refuses a value with a double quote or a control byte, since the TOML of `anti` reads no escape. |
| M14 | fixed | `doc_run` refuses a module path that is not one, and the title, heading, index link and item ids and headings are escaped. |

A fetched file that fails its digest now leaves the cache. The audit named
that beside S45.

## Tests

- `unit`, `tests/unit/test_deps.c`: `version_bounds`, `path_parts` and the
  M12 cases of `urls`. 29 checks failed before the fix
  (`build/drive/logs/unit-red.log`).
- `anti_build_inputs`, `tests/run_anti_build_inputs.cmake`, new. It covers
  a malformed `index.toml` (a version with a path, a version of twenty
  digits, a version with a double quote, a module path and a dependency
  name that climb out of the cache, a constraint that is no version) and a
  malformed `anti.lock` (a version with a path, twenty digits, a module
  path with a path, a digest with a quote). Before the fix the build wrote
  `escaped/` beside the cache (`build/drive/logs/inputs-red.log`).
- `anti_doc`: a library file whose module path is `../../../escaped.x`,
  and one whose item name holds markup. `tests/doc/antl_rename.c` writes
  both, since a CMake script cannot write NUL bytes. Before the fix the
  page was written outside `-o` (`build/drive/logs/doc-red.log`).
- `anti_sdk`: a `Version` of `/../../victim`, on a Mac. Before the fix
  export deleted the victim directory (`build/drive/logs/sdk-red.log`).

## Gates

- Build: no compiler warning in `build/drive/logs/build-host.log`,
  `build-asan.log` and `build-ubsan.log`. Apple ld prints
  `ignoring -lto_library`, because the pinned clang of `ANTI_DEPS_DIR`
  lacks `libLTO.dylib`. That is a note of the linker on every link, not
  of this change.
- Host 794 of 794 (`build/drive/logs/ctest-host.log`), ASan 793 of 793
  (`ctest-asan.log`), UBSan 793 of 793 (`ctest-ubsan.log`).
- The docs-style checker reports nothing on every touched C file, on
  `tests/run_anti_build_inputs.cmake`, `docs/decisions-tool.md` and this
  report. It reads `tests/CMakeLists.txt` as Markdown and reports 206
  findings there at the base commit, one per comment block taken as a
  heading. The new comment block adds one more of that kind.

## Decisions

Every decision is `[provisional]` in `docs/decisions-tool.md`, under
"Step 14, repository inputs": the version grammar and its bound, the name
and digest grammar, the refusal of a whole index, the lock that is not
read, the refusal in `lock_write`, the removal on a digest mismatch, the
loopback rule, the SDK version grammar and the refusal in `anti doc`.
