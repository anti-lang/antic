# Solid: step 2, the checks of the plugin loader

The step fixed the three findings of step 2 of "Fix steps" in
`docs/audit/summary.md`: S309, S310 and M309, in one session on
2026-10-16. Each starts with the test that shows it, and each failed
before its fix. The logs lie in `build/drive/logs/`, under names that
start with `step2-`.

## Findings closed

| Finding | Commit | Cause |
|---|---|---|
| S309 | `45aed114` | The loader wrote its table of stubs into the object itself when the class inherits the interface at offset 0, so the class's own functions stood behind stubs and the table on the heap named no library to the count of live objects. |
| S310 | `32400589` | `damage_of` tested the counts of the entries, the classes and the version chain for a sign alone, and `fields_sound` took an offset up to the size of the object without the width of the field. |
| M309 | `06109ee3` | `joined` wrote an empty directory of the search path as nothing, so the digest read a bare name in the working directory that `dlopen` looks for on the path of the system. |

`72b1c807` writes the commit of each into its row of the summary.

- S309. `plugin_versions` loads a library built against the earlier
  interface whose class inherits it into a host that calls through
  `reflect.call`. The host calls the class's own function and unloads the
  library. It aborted on the stub before the fix. A second line loads a
  class that implements the interface as a sub-object, which keeps its
  table of stubs. `reflect.call` names a function by the descriptor of the
  object's class, so no slot it reaches there is one the library lacks.
- S310. `rt_plugin_table` tries counts past their lists and fields that
  pass the object: scalars, a `str`, arrays, an inline struct, a field of
  that struct, and a struct reached through an owned pointer. Every
  descriptor a field reaches is checked once, from a list the loader
  walks while it grows, so a type that holds itself through a pointer
  ends. The unit tests of the loader now link `object.c`, `json.c` and
  `cast.c` of the runtime for the sizes of the types, in place of a copy
  of `anti_rt_body_entry`. The library of `plugin_kinds` carries a class
  with a field of every kind, which the checks pass. A probe that refused
  arrays of two levels made that test fail, so the checks reach it.
- M309. `rt_plugin_table` discovers `plugin_bad` from its own directory
  through `:nowhere` and `nowhere:`. The index the loader asked for was
  `anti-plugins.toml` before the fix and is `./anti-plugins.toml` after.
- The runtime every program links changed, so
  `link_identity_macos-arm64` takes the new digest of `return42` in
  `4cef37e7`. `emit_identity` is unchanged.
