# R23: the root class and Job move to anti.lang

The compiler declared the root class as `anti.rt.Object` and the result of `dispatch` as `anti.rt.Job`. The runtime defined the root's functions, descriptor and ancestors as `anti_rt_Object_*`. Both types now carry the path `anti.lang`, and the runtime symbols are `anti_lang_Object_*`. The R23 entry is gone from `docs/decisions.md`.

## What changed

- `src/types.c` declares `Object` and `Job` under `LANG_MODULE`. `src/types.h` names both beside the other names of `anti.lang`, and `types_is_job` recognises a Job.
- `src/target.h` names the runtime prefix of the root once, as `RUNTIME_ROOT`. `src/lower.c` and `src/whole.c` build every root symbol from it: the functions, the descriptor, the ancestors and the registry reader `anti_lang_Object_deserialize`.
- `rt/object.c`, `rt/object.h`, `rt/registry.c` and `rt/registry.h` define the new symbols.
- The library format rises from 40 to 41, because a file of version 40 names the root under `anti.rt`.
- `src/header.c` names `anti.lang.Object` in the comment of every table type. The pinned headers `tests/dump/canvas.h` and `tests/dump/failing.h` follow.
- `tests/clib/canvas.c` declares `anti_lang_Object_hash` and calls it on two squares. It links against the static library and the runtime, and the program runs, in C11 and in C++17. The expected output gains `1 1`.
- The IR dumps `tests/dump/devirt.*`, the hex of `scale.antl`, the unit tests, the emit manifest and the link digest follow the rename.
- The documents: R23 removed, the version line of the library format now reads 41, `docs/anti-language-additions.md` and the "Built" line of the syntax overview no longer say the code uses `anti.rt`, `docs/notes/whole-program.md` names the new symbols, and `CLAUDE.md` states where the two types live.

## What failed and how it was fixed

- The first build after the rename left the library file of `anti.lang` treating the root as a class of its own, since both share a path. The writer now declares neither the root nor a Job, and the reader takes the compiler's root for `anti.lang.Object`. Removing that guard again made 15 tests fail to link on `anti.lang.Object.hash` and its siblings (`build/drive/logs/test-mut.log`), so the suite pins it.
- `struct_descriptor` in `src/lower.c` skipped a Job by its module `anti.rt`. It now asks `types_is_job`, so a Job still gets no descriptor.
- `antl_scale` failed on the version byte alone. `emit_identity` changed 318 of 516 digests. Every one of the 318 maps back to its old digest when the new prefix is replaced by the old, so the change is the rename and nothing else. The manifest was rewritten with `WRITE=yes`. `link_identity_macos-arm64` changed because the build id hashes the runtime library, and the Mac's digest was written.
- The docs-style checker flagged one sentence of the new test comment and three older comments of `tests/unit/test_optimize.c`. All four were reworded.
- `docs/decisions.md` gave the library format as 39 while the code held 40. The line now reads 41.

No `[provisional]` entry was added.
