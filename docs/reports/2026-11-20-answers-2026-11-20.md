## Items

  `struct anti_module` of `src/rt/object.h`, and `serialize` writes
  `module.Class`. A module writes the record as `<module>:written`
  wherever it writes a class descriptor of the module, and the link
  keeps one, as for the data of a copy, so a copy of a generic of
  another module finds it. The runtime defines `anti_rt_lang_module`. The
  loader of a plugin refuses a damaged record. The format version of a
  library file is 99.
- 2. The handler of a call whose `*Kid` a binding of a `?*Base` or a
  `?*Counter` takes yields the type of the binding. The success path
  moves the pointer to the sub-object before the join.
- 3. The reader of a library file gives the copy that an `export type`
  of the file names its C name, and the header writes `Ints` where it
  wrote `Stack<i32>`.
- 4. The C name of a `?T` writes the length before a user type name,
  `anti_opt_9slice_int`. No header holds a `?[]int`, since C cannot
  represent a slice, so the test shows the struct alone.
- 5. `reflect.call` of a function that may fail runs it and fails with
  its error. The text of its signature stands after `!`.
- 6. No code. The entry of T348 loses its tag.
- 7. The structural hash names `c_long`, `c_ulong`, `c_wchar` and an
  enum by its qualified name. `plugin_versions` refuses a library built
  against an entry of another such type.
