## T265, the defaults of a file

`declare_fields` of `src/antic/sema_declare.c` checked each default
while it declared the fields of its type, so a default that named a type
declared later was refused. The fields of every struct, union and class
are now declared first, and `check_field_defaults` checks and evaluates
every default in a second pass. `complete_defaults` and
`holds_short_class` are gone, and a new DESIGN names T149 and T265.

The two passes alone still refused a default that is a literal of a copy
of a generic declared later, `Box<int> { x: 5 }`. The copy took its
fields from the generic only when the generic was ready. A copy is now
filled with the fields of its generic in the first pass, as before.
`sema_generic_defaults` of `src/antic/sema_generic.c` gives each filled
copy the values of the defaults of its generic after the second pass.
`matrix/classes_default_literal_of_a_generic_declared_later` holds the
case in the three modes, and it failed before the change. The change
reaches `sema_generic.c` and `sema_checker.h`, and it changes no settled
decision. The tests of T149, `modules_later_class_default_release` and
`modules_later_class_default_dev`, pass.

## T267, the guard of `compute`

The guard of `compute` in `src/antic/layout.c` wrote its message for an
aggregate whose layout depends on itself. The outer layout then ended,
and `flatten` recorded the members through the field of its own type
until the stack overflowed. `holds_itself` of `tests/unit/test_layout.c`
builds a struct that holds itself and two that hold each other by hand.
The runner of `unit_layout` reported the bus error as an ordinary
failure, so the listed test held, and lldb showed the overflow in
`flatten`. A failed layout now records no members. The module is refused
with the first message, and nothing reads the members of a refused
layout. The guard stays, and its row in `docs/notes/unreached-guards.md`
names the unit test.

## The page of a class

`body_entries` of `src/antic/docpage.c` writes the fields, then the
constants and the static fields, then the functions, each group in the
order of the body, in the HTML and in the Markdown. The entry under "The
doc command" lost its `[provisional]` tag. The three pages of `shapes`
that hold `Canvas` changed, and `anti_doc` still finds the page of the
library file equal to the page of the source. `docs/notes/doc.md` and
`docs/tooling.md` state no order, so they did not change. The page of a
module keeps the order of the source.
