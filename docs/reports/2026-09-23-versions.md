# Interface versioning

The "Versions" section of `docs/anti-language-additions.md` is built.
That is the version of the package in every class descriptor and the
structural hash and the chain of an abstract class. It is `compatible`,
the used-slot bitmaps and the three load checks as well.

## What was done

- `src/lower.c` gives every class descriptor three fields after the
  function list: the version of the package that declared the class, its
  length, and the version record of an abstract class. The record holds
  the chain and the floor. The chain is one FNV-1a per prefix of the
  table, so entry k is the hash of the version whose table held k
  entries. `--package-version` reaches lowering through the driver, and
  `PACKAGE_VERSION_DEFAULT` is the `0.0.0` a build without one writes.
- `compatible <version>;` parses as a contextual word where a field of an
  abstract class body stands. The checker refuses it on a class that is
  not abstract, and the library file carries it from format version 50.
- `src/whole.c` copies the chain, the field count, the size and the
  version of each interface a plugin provides into the library's own
  image. A reference to the interface's globals would resolve against the
  host at load. It would then give the host's numbers.
- `anti_rt_slots` keeps the slots the program's calls reach and gains a
  flag `reflect` for a program that calls `reflect.call`. Every program
  carries the table, empty where its calls reach none.
- `rt/plugin.c` compares the two chains at the length of the shorter and
  refuses a version below the floor. It refuses a field count or a size
  that differs, and a reached slot the library lacks, naming the
  function. A slot that reflection alone may reach is filled with a stub,
  in a table the loader writes for the sub-object.
- `--anti.inspect` prints the version and the used slots of each
  injectable interface.
- `tests/plugin/versions` holds five versions of one interface and a host
  per shape. `plugin_versions` loads an older library and a newer one. It
  refuses one that lacks a called function, one whose interface grew a
  field and one built below a `compatible` floor.

## What failed and how it was fixed

- The wider descriptor and the new slot table changed every golden IR
  listing and the assembly of six targets. They changed the byte listing
  of a library file and the two identity digests. The listings were
  regenerated from the commands the tests run.
  `run_emit_identity.cmake -DWRITE=yes` wrote the manifest, and
  `build/drive/logs/test.log` holds the runs.
- The first pass at the expected strings of the unit tests read the test
  output back and merged two records. It wrote one failure's text into
  another's expectation. The fix was markers around each block while the
  strings were rewritten, and `tests/unit/check.h` is as it was.
- `program_by_reverse` and fifty-five others failed to link with
  `anti_rt_slots` undefined. The reader of the configuration file calls
  the loader, so the runtime archive puts the loader in every program.
  Every program carries the table now.
- The loader could not tell a library that needs no stub table from one
  whose table it could not allocate. It would have left a sub-object with
  a table too short. `needs_stubs` answers the first question now and
  `stubs_of` the second.

## Decisions

`docs/decisions.md` gains a "Versions" section with twelve entries,
eleven of them `[provisional]`: the form of the structural hash, the
chain as the prefixes of the table, the one comparison at the length of
the shorter chain, the field count and the size as "no field was added",
the chain alone as the floor without a `compatible` line, the form of
that line, the version a plugin records, the version every descriptor
carries, the two kinds of slot reach, the stub and what
`--anti.inspect` prints. `docs/notes/versions.md` holds the choices of
the passes.

## Open

- `anti.reflect` refuses an index past the function list of the object's
  own class, so no program reaches the stub through that module today.
  The stub keeps a call at a slot the host knows and the library lacks
  from reading past the library's table. No test calls one.
- A `compatible` line takes `1`, `1.1` and `1.1.0`. A version with a
  suffix, such as `1.1-rc1`, is no number of Anti and the parser refuses
  it. The specification writes neither.
