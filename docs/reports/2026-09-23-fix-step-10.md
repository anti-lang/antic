## Tests first

Red runs are in `s10-unit-red.log`, `s10-unit-red37.log` and
`s10-unit-ubsan-red11.log`. S28 and S29 gave wrong answers, and M9 hung
until the alarm stopped it. The S37 test failed against a stub. The S11 test
needs 310 million continuation bytes and shows the defect only under
UBSan, at `symbols.c:100`. The Mach-O readers bounded every read already
and needed no change.

M1 has no test. A read error after a successful `fopen` needs a failing
device. A short image also gave the same trace output as no image. No test
through the public functions tells the two apart.

S37 runs on Linux alone. The host tests the helper, and the cross build of
`trace.c` for the six Linux runtimes compiled it with warnings as errors.
It did not run on a Linux machine in this step.
