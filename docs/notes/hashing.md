# Hashing and order

Choices made for "Hashing and order" of round five in each pass. They
describe the inside of the compiler and the runtime. `docs/decisions.md`
holds what a reader of the language or a user of the tools can observe,
under "Generics and collections".

- `hash` is the twentieth name of the operator table, `LANG_HOOK_HASH` of `sema_checker.h`. `check_hook` of `sema.c` wants `operator fn hash(self) -> u64` and refuses the form in a class body, and `refuse_redeclared` passes over that case, so the class gets the one message that names `concrete fn hash`.
- `sema_hash.c` holds the checker's part. `sema_check_call` hands it `x.hash()` with no arguments, on a type without a field of that name. A class, a `*C`, and a struct or variant whose `sema_hook` finds `operator fn hash` leave the call to `method_call`. Every other type marks the call `hashes`.
- A default hash walks the type it hashes and makes one checked call per struct or variant inside it that has `operator fn hash`. The call is `x.hash()` on a receiver that is never lowered, a `*` of a `none` typed as a pointer to the type, marked prechecked. `method_call` rewrites it as it rewrites code written by hand, so a generic `operator fn hash` records the arguments of its copy there. The calls stand in `hash_calls` of the call, and `types_hash_call_type` gives the type of each from the first parameter of its function.
- A class value inside a default hash needs no such call. Lowering takes the `hash` of the lowest class of its chain with `lower_level_fn`, or `anti_lang_Object_hash`, and calls it directly.
- `x.hash()` on a value of a type parameter checks the hook with `sema_param_hash` and gives a `u64`. The call keeps its receiver typed as the parameter. `open_node` of `sema_copies.c` takes that call, and a default hash of a type that names a parameter, as nodes a copy reads again. The copy clears `hashes` and `hash_calls` and checks the call with the type of the argument, which gives the call of a method, the default and its calls, or the instruction path of a scalar. `xe` and `redirect` walk `hash_calls`, so the in-place walk of the code that is not generic names the copies there.
- `lower_hash.c` writes the default from the type. A scalar goes through `mix`, a float through a slot of its bits with a mask from `fne` against zero, and a pointer through a slot as well, since the IR converts no pointer to an integer. A run of parts is a loop over the elements with the hash so far in a temporary that `ir_assign` writes. A `?T` and a variant branch on the flag and the tag into one temporary. The first field of a struct is read at the address of the struct, as every other part of lowering writes it: `split_slots` of the optimizer took a `ptradd` of `offset_of` the first field for another field and read a temporary that nothing wrote.
- `src/rt/hash.h` holds the three constants and `anti_rt_hash_mix`, which antic and the runtime both read, as `f16.h` holds the conversions. `src/rt/hash.c` holds `anti_rt_hash_bytes`, the seed and its choice at start. `anti_rt_init` calls `anti_rt_hash_seed_start` first. The seed is an atomic `int64_t`, which `anti_rt_hash_seed_set` of the key `hash_seed` writes when its layer wins.
- `anti_rt_entropy` of the platform layer fills bytes from `arc4random_buf`, `getrandom` or `rand_s`. `platform_windows.c` defines `_CRT_RAND_S` before its first header for the last.
- A function of a library file written `operator fn` carries bit 6 of its flags, which `sema_interface` takes from the item and the reader puts in `is_operator` of the symbol. `symbol_is_operator` of `sema_expr.c` reads the item where there is one and the flag otherwise. The tree of a generic carries `hashes` and `hash_calls` after `pattern` of a call.
- `Ordered` has an item in `src/std/anti/lang.anti` and a bare name in `add_constraint`, `ordered_hooks` beside `number_hooks`.
- The tests: `programs/hash_builtin.anti`, `hash_default.anti` and `hash_generic.anti` with their `_dev` runs, `hashing_modules_release` and `hashing_modules_dev` over `tests/modules/hashing/`, `listing_error_hashing`, and `conf_hash_seed_option`, `_file`, `_configure`, `_range`, `_text` and `_random`.
